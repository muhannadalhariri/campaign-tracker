# 🕸️ متتبّع الحملات المنسّقة — Campaign Tracker

أداة لتتبّع **السلوك المنسّق غير الأصيل** (Coordinated Inauthentic Behavior) على فيسبوك:
حملات تضليل تسعى لإثارة الرأي العام ونشر الشائعات. تبدأ الأداة من **نقطة انطلاق**
(منشور، أو صفحة، أو مجموعة صفحات، أو رابط خارجي يُروَّج له)، ثم تتوسع قفزة بعد قفزة
لتكشف الشبكة المحيطة بها وتعرضها كشبكة تفاعلية.

> ⚖️ **التنسيق ليس دليلاً على التضليل بحد ذاته.** الأداة تكشف صفحات تنشر المحتوى نفسه
> بشكل متزامن ومتكرر، ولكل ارتباط أدلة قابلة للتحقق. لا تُنسب أي صفحة لحملة علناً قبل
> مراجعة بشرية، والتركيز على **الصفحات والسلوك** لا على الأفراد.

## كيف تعمل

```
نقطة الانطلاق ─► البصمة (روابط، نصوص، صور) ─► من نشر نفس البصمة؟
      ▲                                             │
      │                                             ▼
 توسيع من المقبولين ◄── مراجعة بشرية ◄── تقييم التنسيق وتصفية الضجيج
                                                    │
                                                    ▼
             الشبكة · التجمعات · المصدر الأول · الخط الزمني · تقرير الأدلة
```

### إشارات التنسيق
| الإشارة | المعنى |
|---|---|
| **نفس الرابط خلال ثوانٍ** | منهجية CooRnet: صفحات تنشر الرابط نفسه بفارق أقل من 60 ثانية (قابل للتعديل) |
| **نص شبه مطابق** | نسخ ولصق مع تعديلات طفيفة. يُطبَّع النص العربي (التشكيل، التطويل، الهمزات، التاء المربوطة) لكشف محاولات التمويه |
| **نفس الصورة** | بصمة إدراكية (perceptual hash) تكشف الصورة حتى بعد القص أو الضغط |
| **تكرار الحدث** | حدث واحد صدفة؛ الارتباط لا يُنشأ إلا بعد عدد أدنى من الأحداث (3 افتراضياً) |
| **معرّفات التتبع المشتركة** | مواقع "مستقلة" ظاهرياً تحمل نفس معرّف Google Analytics أو AdSense، أي أنها تُدار من الجهة نفسها |
| **مؤشرات الصفحة** | صفحات أُنشئت في الأسبوعين نفسيهما، ومشرفون من البلد نفسه، وتغييرات متكررة للاسم |

تُستبعد تلقائياً المواقع التي يشاركها الجميع (يوتيوب، ووكالات الأنباء الكبرى...)، ويمكن إضافة غيرها من الواجهة.

### المخرجات
- **شبكة تفاعلية:** الألوان تمثل التجمعات (خوارزمية Louvain)، والمرشّحون الذين لم تُراجَع صفحاتهم بلون رمادي، والمواقع الخارجية مربعات، والخط الأحمر المتقطع يربط مواقع ذات ملكية مشتركة.
- **السرديات:** لكل موجة محتوى منسّق يظهر **المصدر الأول** ("المريض صفر") وسرعة انتشارها، مع خط زمني.
- **تقرير الأدلة:** بصيغ JSON و CSV، والشبكة بصيغة GEXF للفتح في Gephi.
- **حفظ التحقيقات:** في SQLite (نقطة الانطلاق، والمعايير، وقرارات المحلل).

## التشغيل

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/generate_sample_data.py   # بيانات تجريبية وهمية بالكامل
streamlit run app.py
```

للتجربة: اختر "بيانات تجريبية"، وأدخل المنشور `p00004`، ثم راجع المرشّحين أو اضغط
"قبول آلي لقفزتين". جرّب أيضاً الصفحتين `O01` و `O02`، وهما صفحتان عاديتان، ولاحظ أنه
لا يظهر أي ارتباط.

الاختبارات: `pytest`

## مصادر البيانات

الأداة **لا تسحب بيانات فيسبوك آلياً (scraping)**، فذلك يخالف شروط Meta ويعرّض المحلل
للحظر ولمخاطر قانونية. كل مصدر بيانات هو "موصل" (Connector) يطبّق واجهة واحدة
(`tracker/connectors/base.py`):

| الموصل | الحالة |
|---|---|
| **CSV** (جمع يدوي أو تصدير من أدوات مشروعة) | ✅ جاهز |
| **Meta Content Library API** (للباحثين المعتمدين) | 🔜 هيكل جاهز في `meta_content_library.py` |

### صيغة ملفات CSV

**`posts.csv`** (إلزامي)

| العمود | ملاحظات |
|---|---|
| `post_id`, `page_id`, `created_at` | إلزامية. التاريخ بصيغة ISO 8601 |
| `text` | نص المنشور. تُستخرج الروابط الموجودة فيه تلقائياً |
| `permalink` | رابط المنشور على فيسبوك |
| `links` | روابط خارجية، يُفصل بينها بـ `\|` |
| `image_phash` | بصمة الصورة (hex)، مثلاً من مكتبة `imagehash` |
| `reactions`, `shares`, `page_name` | اختيارية |

**`pages.csv`** (اختياري): `page_id, name, created_at, admin_countries, name_changes, followers, category`
(تُؤخذ هذه البيانات من قسم "شفافية الصفحة" على فيسبوك)

**`domains.csv`** (اختياري): `domain, tracking_ids, registered_at, registrar`

## بنية المشروع

```
tracker/
  normalize.py      تطبيع النص العربي والروابط
  similarity.py     تشابه النصوص (TF-IDF على مقاطع الحروف) وبصمات الصور
  coordination.py   كشف التنسيق والأدلة وموجات المحتوى
  expansion.py      التوسع من نقطة الانطلاق مع المراجعة البشرية
  network.py        بناء الشبكة والتجمعات والمواقع والسرديات
  report.py         تصدير الأدلة
  store.py          حفظ التحقيقات (SQLite)
  connectors/       مصادر البيانات
app.py              واجهة Streamlit (عربية، من اليمين لليسار)
scripts/generate_sample_data.py   بيانات تجريبية وهمية
```

## الخطوات القادمة
- موصل Meta Content Library عند توفر الوصول.
- موصل Meta Ad Library (الإعلانات السياسية والجهات الممولة).
- حساب بصمات الصور من الملفات مباشرة.
- نماذج embeddings متعددة اللغات لكشف إعادة الصياغة، وليس النسخ فقط.
- فحص WHOIS ومعرّفات التتبع للمواقع آلياً.

---

**English summary:** a seed-based investigation tool for coordinated inauthentic behavior on Facebook.
From a seed post, page(s) or pushed link it fingerprints content (links, Arabic-normalized text, image
hashes), finds pages publishing the same content within short windows, keeps only *repeated*
coordination, and lets an analyst accept or reject candidates before expanding the next hop. Output: an
interactive network (Louvain communities, websites linked by shared analytics IDs), narrative origins
and timelines, and exportable evidence. Data sources are pluggable connectors; no scraping.
